# Convenciones de redacción del proyecto

Estas reglas aplican a todos los documentos del repositorio: README, bitácoras semanales y textos del protocolo de investigación.

1. **Terminología.** Para la evaluación inicial de gravedad del paciente al llegar a urgencias se usa "clasificación de gravedad". No se usa el término en inglés ni su traducción literal.
2. **Nombres de eventos del log.** Los nombres tal como aparecen en el archivo (por ejemplo, `ER Triage` y `ER Sepsis Triage`) se escriben en formato de código, sin modificarlos. Se explican la primera vez que aparecen.
3. **Estilo.** Académico, conciso y directo. Cada afirmación tiene cita o remite a un archivo del repositorio.
4. **Cifras.** Una misma cifra se escribe igual en todo el documento. Por ejemplo, la proporción de positivos es 10.5 % (110 de 1,050).
5. **Vocabulario de decisiones.** D = decisión; R = regla fijada antes de revisar resultados; "pendiente" = sin evidencia suficiente para cerrarla.
